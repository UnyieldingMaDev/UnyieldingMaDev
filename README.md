## 项目经历

### 智慧眼 - 深地空间行为安全高精度视觉检测系统

省级大学生创新项目第一负责人。面向复杂井下环境构建危险行为识别、告警、抓拍、日志和联动控制系统；负责基于深度残差网络与子像素卷积的单帧图像超分辨率重建。

### 无线人体生理参数监测系统

省级大学生创新项目核心成员。实现心率、血氧和体温的实时采集、显示、无线传输与远程监测；负责硬件电路设计与焊接、传感器采集、板间通信及上位机通信。

### 运动目标控制与自动追踪系统

使用 MCU、摄像头、二维舵机云台和激光模块完成目标定点、固定路线移动与视觉自动追踪；负责目标识别及云台控制。获全国大学生电子设计竞赛江苏赛区二等奖。

### 三子棋游戏装置

以 MaixCAM 为主控，结合摄像头、舵机和机械结构实现人机三子棋博弈；负责机械结构、舵机控制与 Minimax 算法。获江苏省 TI 杯电子设计竞赛一等奖。
